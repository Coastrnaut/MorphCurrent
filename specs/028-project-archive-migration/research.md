# Research: F28

- **Decision**: Standard zip with deflate, members at repository-relative paths. **Rationale**: inspectable with ordinary tools; the imported folder is directly re-plannable by `compile_plan(repo_root=dest)`. **Alternatives**: tar (less native on Windows), custom container (opaque).
- **Decision**: Check limits from the zip central directory (`ZipInfo.file_size`, `compress_size`) before decompressing, and verify checksums by streaming (`ZipFile.open` in chunks, aborting if bytes read exceed the declared size). **Rationale**: archive-bomb protection without trusting declared sizes alone.
- **Decision**: Name safety rejects `..`, leading `/`, backslash, `:` anywhere (drive letters and alternate data streams), names ending in space or dot, reserved device names (CON, PRN, AUX, NUL, COM1–9, LPT1–9, with any extension), duplicates and case-insensitive collisions. Import additionally resolves each target and asserts it is inside the staging folder. **Rationale**: Windows path semantics.
- **Decision**: Absolute-path detection in JSON: strings matching a drive letter (`^[A-Za-z]:[\\/]`), UNC (`^\\\\`), or POSIX home/temp roots (`^/(home|Users|tmp|var|mnt)/`). Redaction rewrites those inside run/repo to relative POSIX names, else the marker. **Rationale**: removes the owner's folder structure without breaking relative references.
- **Decision**: Format 0 = F20 run backup, detected by `SHA256SUMS.json` + `run/` members + no `project.json`; migrated in memory to a format-1 description; its member layout is kept for import. **Rationale**: real older archives exist on this machine.
- **Decision**: Migration functions are pure (deep copy in, new dict out); the runner stops at the first failure and raises with the step name. **Rationale**: rollback by construction.
