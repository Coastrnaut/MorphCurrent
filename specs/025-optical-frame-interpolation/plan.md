## Summary

New `src/morph_studio/interpolate.py`:
- `FILTERS` = repeat `fps=N`, blend `framerate=fps=N`, motion `minterpolate=fps=N:mi_mode=mci:mc_mode=aobmc:me_mode=bidir:vsbmc=1:scd=fdiff`.
- `anchor_alignment(duration, fps)`: exact rational check of every 0.25 s mark via `fractions.Fraction`.
- `convert(input, out, fps, method, crf=16)`:
  1. Refuse an existing output.
  2. Hard-cut check via `qa.analyze_clip` (falls back to repeat if a cut is found).
  3. FFmpeg into `out.part`, then rename.
  4. Probe and check the duration.
  5. Write a sidecar `<out>.interp.json` with checksums, the filter string, the FFmpeg version and the results; verify the input checksum is unchanged.
- `warp_times(map)` (inverse map → per-source-frame start times).
- `apply_warp(clip, map, out)`:
  1. Decode the frames to temporary PNGs in a scratch dir.
  2. Build an ffconcat list with per-frame durations.
  3. Run `fps=16` (nearest).
  4. Write the output and a `.warp.json` sidecar.

CLI: `interpolate INPUT --fps N --method repeat|blend|motion --out OUT [--crf]` and `warp-apply CLIP --map MAP.json|--plan PLAN.json --bridge K --out OUT`.

## Technical Context

**Language/Version**: Python 3.11+

**Primary Dependencies**: stdlib (`fractions`, `subprocess`, `tempfile`, `json`); local FFmpeg/ffprobe; existing `media.probe_video`, `qa.analyze_clip`, `cache.sha256_file`

**Storage**: new output files + sidecars chosen by the user; temporary frame PNGs in a temp dir (removed after use)

**Testing**: pytest with synthetic clips generated by FFmpeg (brightness = frame index; hard-cut clip); FFmpeg-gated

**Target Platform**: native Windows 11

**Project Type**: CLI tool

**Performance Goals**: a 65-frame 832×480 bridge converts in seconds

**Constraints**: originals immutable; no GPU; no learned models

**Scale/Scope**: whole film (~6 min) conversion in one call
